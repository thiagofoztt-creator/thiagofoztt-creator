Plataforma de gestão condominial que integra aplicativo Android, painel administrativo web, portal do morador e API REST desenvolvida em PHP.

**Principais recursos:**
- Gestão de moradores, funcionários, visitantes e veículos.
- Controle de encomendas, leitura de etiquetas e QR Code.
- Integração de OCR e Inteligência Artificial.
- Autenticação JWT e autorização por perfil.
- Arquitetura multi-tenant com isolamento lógico de dados.
- Dashboard, histórico operacional e auditoria.

**Tecnologias:** Kotlin, Jetpack Compose, PHP, MySQL, REST API e OCR.
